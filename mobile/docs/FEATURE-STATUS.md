## Content requirements 64–69

| Requirement           | Implementation                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 64: Short-form sports | Dedicated SpotUp Moments route; record/pick/upload; captions; sport/category; optional user/location/entity tags; likes/comments/share/save/follow; one active vertical video; mute and native playback controls; For You, Following, Local, Trending, Saved modes. Reactions support like/fire/clap at the API; the current feed UI exposes like.                                                                                                     |
| 65: Skill Showcase    | Separate table, publishing intent, profile section, player-selected sport/category/caption/date, visibility settings and profile/game/squad/tournament pathways. No automatic rating or feed insertion.                                                                                                                                                                                                                                           |
| 66: Safety            | RLS and RPC checks, private media, pending moderation, report/block/delete, moderator audit, spam limits, independent audience policies. Operational moderation and transcoding still need deployment.                                                                                                                                                                                                                                            |
| 67: Retention         | Completed-game → post flow; clips → creator/game/squad/tournament/venue/discovery; player showcase → invite to play. Content earns no participation XP.                                                                                                                                                                                                                                                                                           |
| 68: Discovery         | Candidate-page ranking uses followed players, sports interests, chosen area, shared games, squad context, bounded engagement and recency. Creator diversity prevents one creator dominating a candidate page. Local discovery uses the selected area, not published live location. Trending reranks a recent candidate page by reactions; it is not yet a global trend model. Watch history and tournament-participation ranking are future work. |
| 69: Identity          | Profile brings participation, reliability, squads, achievements, skill evidence and social content together, with visibly separate showcase/social sections.                                                                                                                                                                                                                                                                                      |

## Next release sequence

1. Connect Supabase; deploy and exercise the existing flows with real test accounts on two devices. Fix integration differences before expanding scope.
2. Finish remaining Tier 1 coordination: system/host messages, fuller filters, dependable offline behavior, geospatial pagination, reminders.
3. Add standalone results, squad game linkage/stats/invites, streaks, and earned-achievement persistence.
4. Finish content operations: upload retry/resume, server media verification/transcoding, moderation procedures, public deep links, participation attribution.
5. Complete device, accessibility, security, privacy, and app-store release gates.

This sequence preserves the supplied master brief instead of silently treating the entire 69-section scope as finished.
